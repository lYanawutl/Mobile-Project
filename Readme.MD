หน้า Welcome → "เริ่มสั่งอาหาร"
แท็บลูกค้า: แตะโต๊ะว่าง → ใส่จำนวนลูกค้า → "เปิดโต๊ะ" (แตะโต๊ะที่มีบิลอยู่แล้วจะเข้าบิลเดิม)
แตะเมนู → เลือกจำนวน ตัวเลือกเพิ่ม หมายเหตุ → "ใส่ตะกร้า" → ตรวจในแผงตะกร้า → "ส่งเข้าครัว" (หนึ่งครั้ง = หนึ่งรอบการสั่ง สั่งเพิ่มได้หลายรอบ)
แท็บครัว: แตะการ์ดโต๊ะ → เปลี่ยนสถานะทีละรายการ หรือใช้ปุ่มด้านล่าง "เริ่มทำทั้งหมด" → "ทำเสร็จแล้ว" → "เสิร์ฟครบแล้ว"
กลับแท็บลูกค้า → แผง "ประวัติ" หรือหน้าบิล → "ปิดบิล" (ปิดได้เมื่อทุกรายการเสิร์ฟแล้วหรือถูกยกเลิก)
แท็บร้าน: ดูประวัติบิลที่ปิดแล้ว, จัดการเมนู (เพิ่ม แก้ราคา เปิด/ปิดขาย), ล้างข้อมูลการขาย

ระดับ ก (ครบทุกข้อ)

✅ ก1 เลือกโต๊ะ เปิดบิลใหม่ (มีหน้ายืนยัน) หรือเข้าบิลที่เปิดค้างอยู่
✅ ก2 เมนูแบ่ง 5 หมวด หมวดละ 5–6 รายการ รวม 27 รายการ
✅ ก3 เลือกจำนวนและใส่หมายเหตุ
✅ ก4 ตรวจรายการในตะกร้าก่อนยืนยัน แล้วส่งเข้าครัวเป็นหนึ่งรอบ
✅ ก5 สั่งเพิ่มได้หลายรอบในบิลเดียว รอบก่อนหน้าอยู่ครบ
✅ ก6 สรุปบิลแยกทุกรอบ พร้อมจำนวน ราคาต่อหน่วย ราคารวมของรายการ และยอดรวมทั้งบิล
✅ ก7 ครัวเห็นรายการที่ส่งเข้ามา โต๊ะเรียงตามออเดอร์ที่เก่าที่สุดก่อน รายการในโต๊ะเรียงตามเวลาที่สั่ง
✅ ก8 เปลี่ยนสถานะทีละรายการ: รอทำ → กำลังทำ → พร้อมเสิร์ฟ → เสิร์ฟแล้ว (4 สถานะ + ยกเลิก)
✅ ก9 เห็นโต๊ะ รอบที่ และหมายเหตุของแต่ละรายการ
✅ ก10 ปิดบิลแล้วโต๊ะเปิดบิลใหม่ได้ บิลเก่าดูย้อนหลังได้ที่แท็บร้าน

ระดับ ข (ทำ 3 ข้อ)

✅ ข2 ค้นหาเมนูจากชื่อ และกรองเฉพาะรายการที่มีของ
✅ ข3 ยกเลิกรายการที่ยังไม่ได้ลงมือทำ ได้ทั้งฝั่งลูกค้าและฝั่งครัว พร้อมบันทึกเวลา ผู้ยกเลิก และเหตุผล และแจ้งเตือนอีกฝ่ายจนกว่าจะกดรับทราบ
✅ ข5 ตั้งค่าเมนูในแอป: เพิ่มเมนู แก้ราคา เลือกรูป เลือกตัวเลือกเพิ่ม และปิดการขายชั่วคราว

9 ตาราง: categories, menu_items, options, menu_item_options, dining_tables, bills, order_rounds, order_items, order_item_options
9 FOREIGN KEY เปิด PRAGMA foreign_keys = ON ทุกครั้งที่เปิดฐานข้อมูล ส่วนที่เป็นส่วนประกอบของแม่ใช้ ON DELETE CASCADE ส่วนที่อ้างถึงข้อมูลหลักใช้ ON DELETE RESTRICT
